## 实现结果

### 真实素材

素材均保存在 `assets/`，详细来源、提取方式、版本及许可文件见[素材来源说明](../../../assets/SOURCES.md)。本次素材下载与界面实现并行完成，没有新增运行依赖。

- VS Code、Excel、Word、微信、访达、系统设置、备忘录等图标优先取自本机真实应用/系统资源。
- Photoshop 使用 Adobe 官方产品 SVG；Windows VS Code 使用官方无 macOS 底板的平面图标。
- Windows 记事本使用 Microsoft Store 官方目录的蓝色图标；部分 Windows 文件夹、电脑和设置符号使用微软 Fluent 素材，未宣称是 Windows 二进制中的完整程序图标。
- macOS 壁纸取自本机 Sonoma 明亮帧；Windows 11 Bloom 取自原作者 Six N. Five 的公开项目原图。桌面按比例裁切，没有拉伸或 AI 重绘。
- 主壁纸、品牌图标及相关文件全部随静态构建打包；页面不依赖外部图床。
