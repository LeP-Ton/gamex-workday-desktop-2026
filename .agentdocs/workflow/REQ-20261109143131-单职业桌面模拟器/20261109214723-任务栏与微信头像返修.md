## 问题与方案

任务栏的 Windows 按钮约 39 像素，但平台图标容器使用 51 像素内联尺寸；图标图片虽缩小，外层与工作软件图标容器仍保留原尺寸，导致视觉大小、居中和状态指示不一致。微信沿用 macOS 圆角底板图标，设置沿用线框 Fluent 符号，文件夹是通用 Emoji，和拟真的 Windows 任务栏不一致。

微信本人、联系人列表和聊天气泡使用“我、周、林、陈”的色块文字头像，通知也仅显示应用图标。采用四张固定本地照片式头像，统一联系人、聊天、本人及通知的映射；照片中人物均为虚构角色，不对应真实个人。

## 实施范围

- 修正图标外层与图片尺寸，Windows 任务栏统一按 24 像素居中，保持 macOS Dock 的原有尺寸。
- 使用平台对应素材，区分当前窗口、后台已打开应用和未读角标。
- 新增 `ui/avatars.js` 与 `assets/avatars/`，头像只属于界面层，不进入引擎输入、动作或评分。
- 使用 imagegen 内置工具生成周主管、林悦、陈一鸣及本人头像；本人使用日常宠物照片，兼容四职业与玩家身份。原图保留，项目使用 256×256 JPEG 轻量导出。
- 原始提示词与生成文件记录在[头像素材说明](../../../assets/avatars/README.md)，第三方图标来源继续维护在[素材来源](../../../assets/SOURCES.md)。
- 本轮保持网页实现范围，前面的桌面端问答不构成新增桌面工程的实施要求。
